# Practical 1: Project Folder and Terminal Navigation

## Aim
To create a project folder and learn basic terminal commands for navigating directories and managing files.

## Theory
A terminal is a command-line interface used to interact with the operating system. It allows users to create folders, navigate directories and manage files.

## Commands Used

1. pwd - Displays the current directory.
2. ls - Lists files and folders.
3. mkdir - Creates a directory.
4. cd - Changes the current directory.
5. cd .. - Moves to the parent directory.
6. touch - Creates a new file.

## Procedure

1. Open VS Code.
2. Open a new terminal.
3. Create the main project folder.
4. Navigate into the folder.
5. Create the required subfolders.
6. Create a text file.
7. Verify the files using ls.

## Terminal Commands

mkdir Web-Development-Lab
cd Web-Development-Lab

Successfully created the project folder and subdirectories and practised basic terminal navigation commands.
